# GatherMap — decision evidence

**Author:** Babuni.dev

## Design already embodied by code

The map learns from actual gathering instead of a fixed imported database; markers change color with character skill while account-wide discoveries remain available.

This is a source-observed approach, not a claim that a particular discussion approved the architecture.
